# Monet — Kopstrādes telpu platforma

> 📄 **Lietotāja rokasgrāmata (PDF):** [Lejupielādēt sistēmas lietotāja instrukciju (PDF)](monet_instrukcija.pdf)

Kopstrādes telpu nomas un pārvaldības tīmekļa risinājums ar lomu vadību (Viesis, Rezidents, Iznomātājs, Administrators), meklēšanas filtriem, tūlītēju rezervāciju un digitālajiem durvju piekļuves kodiem.
